# Neovim Lua Config
1. For macOS, create a folder named "nvim" in the "~/.config" folder
```cd ~/.config && mkdir nvim && cd nvim```
2. Git clone into the "nvim" folder
```git clone https://github.com/kylechiu3201/Neovim-Lua-Config.git .```
3. Brew install libgit2
```brew install libgit2```
